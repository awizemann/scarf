## Description

When ScarfGo can't read config (e.g. host key changed and the pin refuses, or SSH fails), passModelPreflight gets an empty config and shows the "pick a model" sheet instead of a connection error. Seen 2026-11-24 in the simulator after the test sshd's host key changed. Preflight should distinguish "unreachable" from "not configured" (HermesConfigReader returns nil for both).
