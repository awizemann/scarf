## Description

Filed by P55 (round-6 decision 3), which dropped Scarf's optimistic `/goal` + `/subgoal` mirrors (goal pill, subgoal count, "Goal locked" toast) on Mac and iOS.

Why there is nothing to gate today: `/goal` is a real Hermes command in the TUI and gateway from `hermes_cli/commands.py:103` @ `v2026.5.7` (0.13.0) — **corrected 2026-09-13 by the round-6 memory audit: this ticket said `:113`, which is where that same `CommandDef` sits at `v2026.9.7`; P55b (`e6cfe38d`) fixed the identical paste in two doc comments** — and `/subgoal` from `v2026.5.16` (0.14.0), but the ACP adapter's command table has NEVER carried either at ANY tag — `_SLASH_COMMANDS` in `acp_adapter/server.py:163-173` @ `v2026.5.7` and `SlashCommandsMixin._COMMANDS` in `acp_adapter/commands.py:44-66` @ `v2026.9.7` are nine names each (help, model, tools, context, reset, steer, queue, version, plus `compact` at the older tag where the newer has `compress` — NOT literally "the same nine names", per P55b). An unknown name falls through to the model (`acp_adapter/commands.py:94-95`), so over ACP — which is how Scarf chats — `/goal foo` is an ordinary prompt on every supported host.

Trigger for this task: a future Hermes tag adds `goal` (and/or `subgoal`) to that ACP table. Then, and only then:
- Add the names to `RichChatViewModel.nonInterruptiveCommands` (or a dispatched-slash roster) gated on a new floor flag walked at the adding tag and the tag before it.
- Remove those names from `RichChatViewModel.acpUnhandledSlashNames` so the "sent as an ordinary prompt" notice stops firing above the floor, and keep it firing below.
- Only then consider re-introducing a goal pill — driven by an authoritative read-back (an ACP session notification or `/goal --status` reply), never by an optimistic client mirror. That mirror is what P55 removed.
- `HermesCapabilities.hasGoals` / `hasSubgoal` (floors 0.13 / 0.14, source-verified, currently consumer-free) are the flags to consult only for the TUI/gateway surface; an ACP door needs its OWN floor at the ACP-table tag.

Detection: re-walk `acp_adapter/commands.py` (`_COMMANDS`) at each new tag — the slash-roster note `architecture/the-acp-adapter-s-slash-roster-is-nine-names-and-has-been` is the standing record.
