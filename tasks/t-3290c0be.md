## Description

Hermes v0.20.4 is_job_runnable() (cron/jobs.py:571-582) blocks firing when state=="paused" OR paused_at set, regardless of enabled. Scarf's HermesCronJob.withEnabled(true) (HermesCronJob.swift:172-198, used by IOSCronViewModel.swift:81 file-write path) flips only enabled → job never fires. Fix: enable = state="scheduled" + strip paused_at/paused_reason from extra; disable = state="paused" + set paused_at. Gate on hasCronPauseMarkerGate (macOS CLI pause/resume path unaffected — leave it). Also: map "error" in stateIcon (HermesCronJob.swift:231-239), and harden decode with decodeIfPresent ?? "" for prompt/name/state (null in hand-edited jobs.json currently fails whole-file decode, HermesCronJob.swift:131). Round-trip tests incl. paused_at stripping. Branch feat/hermes-v0204-parity.
