## Description

After Live Voice works end to end. Hermes's GPT-Live mode needs a paid OpenAI key ($0.05/min). Many hosts won't have voice set up or an OpenAI key. Evaluate what Hermes already supports for free and how Scarf should present it:
- Hermes "chained" voice mode (speech-to-text → Hermes → text-to-speech) with free providers: local/faster-whisper STT, edge TTS (free), NeuTTS/Piper/kokoro via a command provider (local).
- On-device Apple options on the Scarf side (SFSpeechRecognizer on-device, AVSpeechSynthesizer) as a zero-setup fallback.
- Whether Scarf should help set voice up (Settings → Voice guidance, provider picker, key status from resolve_gpt_live_status) instead of hiding the feature.
Cite Hermes source at the target tag (charter C2). Output: recommendation for Alan + follow-up tasks.
