## Description

Round-3 whole-surface audit (`documents/hermes-v0.21.1-whole-surface-audit-round3.md`, YAML section). Needs product decision (refuse vs reshape a control character in a user-typed scalar) from the report.

- HIGH · PRE · `ProfileRoutesWriter.quoted` (`ProfileRoutesWriter.swift:211-235`, emitted `:106,108,116`; `quotedID:205-207`) is a fourth, weaker quoting routine: a route Name starting with `}`, `]`, backtick, or carrying a tab/newline, makes PyYAML raise (verified PyYAML 6.0.3) and Hermes discards the entire config.yaml layer (`gateway/config.py:773-792` @ v2026.9.7). `.inf`/`.nan`/`2026-09-09`/`0b101`/`12_000`/`<<`/`=` retype. Route Name is free text (`ProfileRoutesSection.swift:330`).
- HIGH · PRE · `HermesBotProfileYAML.quoted` (`:867-893`) claims "any input round-trips" — fuzzed 6000 inputs, 166 failures (leading `]`/`}`/backtick raise; `<<`/`=` ConstructorError; `.inf`/dates/ints retype). Reached by `display_name`, profile/bot `description`, `title`, `color`, `shape`, `group` (`:284,290,426-438`); failure mode is the file's own "total metadata loss" (`:760-765`, `read_profile_meta` swallows). `YAMLScalar.quoteIfNeeded` passes the same fuzz with 0 failures.
- LOW · PRE · `HermesYAML.parseNestedYAML` is last-wins for duplicate list keys but not for `values`/`maps` (`HermesYAML.swift:209`).
- LOW · PRE (decision) · env fallbacks Hermes reads that Settings does not model: `GATEWAY_MULTIPLEX_PROFILES` (`gateway/config.py:76-95,711-713`) vs `ProfileRoutesYAML.parseMultiplex`; `SLACK_REQUIRE_MENTION` (`plugins/platforms/slack/adapter.py:5923`) vs `HermesConfig+YAML.swift:606`.

Fix shape: route both writers through `YAMLScalar.quoteIfNeeded` (and `containsLineBreak` refusal or `doubleQuoted` per the decision); PyYAML round-trip tests on the fuzz corpus classes.
