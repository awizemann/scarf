## Description

> Imported from gh#140 — https://github.com/awizemann/scarf/issues/140

**Describe the bug**
Viewing a large chat backlog (anything more than 10 visible pages on a laptop screen) puts the CPU to 100%.  Always is 100% when receiving a message, making the system display 2-3 chars/sec.  Navigating away drops the CPU massively.

**To Reproduce**
Steps to reproduce the behavior:
1. Open a new chat session, get it to give you a page or two of response.
2. View local CPU use
3. Profit!

**Expected behavior**
Smoother UI display, not pegging the CPU at the redline.

**Screenshots**
If applicable, add screenshots.

**Environment**
- macOS version: 26.6.2
- Xcode version: N/A
- Hermes version: 2.21.0 (63)
- Scarf version/commit: Latest binary, updated through the app.
