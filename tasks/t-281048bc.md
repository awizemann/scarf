## Description

Found by the UI gate Smoke sweep against the seeded fixture (2026-09-08). Hermes 0.21 writes state.db in WAL mode; when no -shm/-wal sidecars exist (CLI-only users, gateway stopped, fresh homes), sqlite3_open_v2 with SQLITE_OPEN_READONLY in LocalSQLiteBackend.open() fails with SQLITE_CANTOPEN(14) and the Dashboard shows "Can't read Hermes state on Local — state.db". Alan's real home works only because the running gateway keeps state.db-shm alive. Alan's decision: guarded fallback — on CANTOPEN for a WAL database, reopen with SQLITE_OPEN_READWRITE (never CREATE) and immediately `PRAGMA query_only=1` so SQLite can create the sidecars while the connection cannot write a row. Charter C3 reading: sidecar creation is not a state mutation; the query_only guard is what keeps the connection read-only. Tagged charter for Alan's confirmation of the C3 reading.
