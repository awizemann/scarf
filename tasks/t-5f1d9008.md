## Description

Sibling of t-01bd55ec (found in its execution): SessionsViewModel.confirmDelete (Sessions feature) is an independent delete surface that runs the CLI delete but never coordinates with ChatViewModel — deleting the chat-active session from the Sessions tab leaves the ACP client running against a deleted session (same leak/orphan shape t-01bd55ec fixed for the sidebar path). Needs a cross-feature seam: either notify the chat window's ChatViewModel (per-window — mind multi-server windows) or centralize delete-of-active handling. ChatViewModel.deleteSession's teardown block (commit 59485c1) is the reference behavior.

## Plan

1. Seam survey: no custom Notification.Name / event bus exists; the existing idiom is
   `NotificationCenter.default.addObserver(forName:queue:.main) { MainActor.assumeIsolated … }`
   (scarfApp.swift ServerLiveStatusRegistry, t-aud05). Use NotificationCenter.
2. Sessions feature (owned): `SessionDeletedSignal` (name + userInfo keys: sessionId String,
   context ServerContext — full context equality covers ServerID AND profile home) defined in
   SessionsViewModel.swift; injectable `sessionDeleteRunner` (acpClientFactory pattern, mirrors
   ChatViewModel's); `confirmDelete` posts the signal only after CLI exit 0.
3. ChatViewModel (allowed block): extract 59485c1's active-delete teardown into
   `tearDownDeletedActiveSession()` (called by deleteSession + new handler); observer registered
   in init, removed in deinit; handler guards full-context + full-session-id match, purges the
   sidebar caches for the row, runs teardown. Non-matching id/context → strict no-op.
4. Tests (scarfTests, new file SessionDeletedSignalTests.swift reusing
   ChatViewModelStartLifecycleTests' scripted-channel seams): signal-active-mid-turn (cancel sent,
   channel closed, blank idle, delete toast), signal-non-active no-op, signal-other-server no-op,
   SessionsViewModel posts on success / does NOT post on CLI failure.
5. Verify: ScarfCore suite + scarfTests bundle + Mac Debug build; pre-fix failure check on the
   mid-turn test.
