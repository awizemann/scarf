## Description

From the P7 performance audit (documents/reports/2026-09-03-projects-full-surface-audit.md): ~55-70 SSH round-trips per coalesced watcher tick during an active stream. (1) Cockpit: mtime/short-circuit fast path in ProjectCockpitViewModel.loadImpl (or dashboard-only tick reload) instead of 8-12 round-trips of full facet reload per tick (ProjectCockpitView.swift:80-82); stop unconditional @Observable reassignment. (2) ProjectMenuProbeCache.refresh decoupled from the tick — probe at install/uninstall/selection time (~40 round-trips/tick today). (3) Single dashboard decode per tick — drop the sidebar's redundant read (ProjectsViewModel.reloadDashboard vs cockpit; sidebar needs only existence for its icon). (4) HermesFileWatcher.updateProjectWatches must diff the path set — no remote poller teardown/re-baseline and no local source rebuild when unchanged (:271-296). (5) Async-ify the main-actor mutator IO (closes the P2 deferral; sidebar click = 2 blocking SSH ops, rename = 3-5; charter C10). (6) Widget reads: size caps for markdown_file/image (parity with the 4MB registry cap), NSImage downsampling to display size, mtime short-circuit per tick. (7) Doctor scan must not trigger from a tick (ProjectHealthCache expiry + force reload interplay); refresh on user action/selection only. (8) Mini-app scheme handler: move the up-to-64MB read off the main thread if the stopped-task crash class allows, or lower the cap.

## Plan

All eight scoped items landed. macOS + iOS build; ScarfCore 2065 + 38 tests and scarfTests 689 pass.

**H1 cockpit facet short-circuit** — `ProjectCockpitViewModel` computes a `path -> mtime:size` map over the 8 facet inputs (+ each discovered `miniapp.json`) in ONE batched `transport.statAll`, and a `.watcher` load whose signature matches the last one returns before reading anything and before touching any `@Observable` property.

**H2 menu probe cadence** — `ProjectMenuProbeCache.refresh` no-ops for an unchanged project set on the same host, with a 60s revalidation floor (an agent can install a template behind our back) and an explicit `invalidate()` wired into the template install + uninstall sheets.

**H3 single dashboard decode** — `ProjectsViewModel.dashboard` / `dashboardError` / `loadDashboard` removed; the sidebar glyph reads `selectedHasDashboard`, one off-main `stat`. The cockpit remains the only decoder.

**H4 watch diffing + remote baseline** — `updateProjectWatches` keys `projectSources` by path and touches only the difference; an unchanged set is a no-op (no local rebuild, no SSH poller restart). `unarmedProjectPaths` keeps the free retry the old rebuild was accidentally providing. `transport.watchPaths(_:baseline:)` takes a `WatchBaselineStore` the watcher owns, so a restart no longer swallows the first delta, and the signature is `mtime:size` per path instead of one joined mtime blob.

**M1 async mutators** — every `ProjectsViewModel` mutator, `registryForMutation`, `mutateEntry`, `propagateRenameToRecord` and `cleanUpAfterRemoval` do their transport work off the main actor; `selectProject` touches no transport at all. Closes the P2 deferral and the C10 exposure.

**M2 widget reads** — `WidgetFileRead` adds a 4MB text / 32MB image cap (refusal, never truncation), a stat-first short-circuit so an unchanged file is not re-read or re-decoded per tick, and `CGImageSourceCreateThumbnailAtIndex` downsampling to the drawn size.

**M3 mini-app scheme handler** — the up-to-64MB read moved to a background queue with a main-queue live-task ledger, so the "message a stopped WKURLSchemeTask" crash class is bought back by the ledger rather than by blocking the main thread.

**M4 doctor off the tick** — `ProjectCockpitViewModel.LoadReason` makes the caller's intent the gate: a `.watcher` load never diagnoses, `.userInitiated` (open / refresh button / doctor-sheet close) does, subject to the same 5-minute cache.

**Addendum: stale-overwrite window** — `RegistryLoadResult.contentFingerprint` + `saveRegistry(_:allowEmpty:expecting:)` refuse a write whose baseline no longer matches the file, checked inside the write lock. `nil` baseline = unchanged behaviour.
