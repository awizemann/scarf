## Description

Scarf iOS/Chat/ChatView.swift:2456-2461 catches EVERY loadSession error and silently opens a new session (transcript replay makes it look like a resume; user context/attribution silently lost; no log/analytics — Mac path has both at ChatViewModel.swift:1615,1622). ACPClient.loadSession throws a specific ACPClientError.invalidResponse("… is not restorable") for the legit non-ACP fallback case (ACPClient.swift:300-340). Fix: fall back ONLY on the not-restorable error; transient errors → surface retry/error UI; log + Analytics.record("session_resume_fallback") on iOS matching Mac. Note blast radius grew with v0.20.4 listable reset/branch children feeding the same tap targets (HermesDataService.swift:235-263 → ProjectSessionsViewModel.swift:76 → ScarfGoCoordinator.resumeSession). Evidence: release audit finding 5.
