## Description

Contract: `scripts/ui-fixture/make-ui-fixture.sh <dest-dir>` builds a throwaway Hermes home at dest-dir (creating it), drops the `.scarf-test-home-marker` sentinel, copies config.yaml/auth.json/.env from the real ~/.hermes, then seeds through the installed `hermes` CLI with HERMES_HOME=dest-dir: 2-3 sessions via `hermes chat -z`, a memory or two, 2 cron jobs (paused), 3 kanban cards, 1 installed skill, 1 project. Idempotent, exits non-zero with a clear message on any failed verb, prints the path on success. Every hermes verb/flag used must be verified against the installed Hermes argparse (charter C5) and listed in scripts/ui-fixture/VERBS.md with the check output. Also a `--dry-run` that only verifies verbs. Never writes to the real ~/.hermes. Runtime target under 2 minutes.
