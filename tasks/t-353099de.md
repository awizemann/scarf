## Description

`RichChatInputBar`'s send Button (scarf/scarf/Features/Chat/Views/RichChatInputBar.swift, ~line 246) is icon-only — an `Image(systemName: "arrow.up")` with a `.help("Send message (Enter)")` and no `.accessibilityLabel`. In the accessibility tree it now carries only the `chat.composer.send` identifier added for the UI gate, so VoiceOver announces it as an unlabelled button.

Found while building the Live chat journey (t-d714835d). A `.accessibilityLabel(Text("Send message"))` was written and then deliberately REVERTED out of that commit: it introduces a new user-facing string, and `scarfTests/LocalizationCatalogTests` requires every translatable key to be present in all six shipped locales — so the label needs its catalog entries in the same change, which is out of scope for a test-only commit.

Do: add the accessibility label, run the Xcode string extraction, and translate the new key in all six locales so `everyTranslatableKeyIsLocalized` stays green. Check the attachment button and the compress button in the same file while there — they are icon-only too.
