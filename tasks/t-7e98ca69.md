## Description

Feature A from the 2026-09-04 external-links investigation: new declarable mini-app permission open_url — bridge call scarf.openURL(url), https-only + well-formed host, opens in the macOS default browser via NSWorkspace. Consent-sheet row like any permission (payload-v2 grant signing); per-host memory via the HMAC-signed ImageHostConsentStore mechanism ("Open example.com? / Always allow this host"); never auto-fires — user click required. Fixes the news-tracker article-browser dead links properly.
