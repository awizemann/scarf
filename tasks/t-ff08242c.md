## Description

Root cause: transport keyProvider (ScarfIOSApp.swift:57) and chat ACP keyProvider (ChatView.swift:1515) call compat KeychainSSHKeyStore.load(), which returns the key of the lexicographically-first ServerID among ALL keychain items (which survive app reinstall + can iCloud-sync). Onboarding saves per-entry (save(bundle, for: id)) and Test Connection uses the in-memory bundle, so test passes while every runtime connect auths with a stale/wrong key → sshd rejects publickey → Citadel SSHClientError error 4 (allAuthenticationOptionsFailed). Fix: SSHKeyResolver matching SSHConfig (host, port??22, user) → entry id → load(for:), fallback to compat load(); wire both call sites; map error 4 to a readable auth-failed message; tests.
