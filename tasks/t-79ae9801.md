## Description

Follow-up to step 1 (chained engine, merged 3619f216). For hosts with `stt.provider` set (a tuned groq/local-whisper setup, or languages Apple can't do on-device): record the utterance to a WAV, stage it on the host through the same script-over-transport path HermesSpeechService uses (base64 heredoc, per-user 0700 temp dir, sweep), call `tools.voice_mode.transcribe_recording(wav_path)` (present since March 2026, below the 0.20.1 speech floor; cite at the target tag), and feed the transcript into ChainedVoiceEngine as a second `VoiceListener` conformer (`HostVoiceListener`: local VAD/silence end-of-utterance, no partials). Opt-in toggle in Settings › Voice ("Speech to text: on this device / on the Hermes host"), consent copy that says audio leaves the device for the host, and a warning when the host's STT autodetect ladder (local → groq → openai → …) would reach a paid cloud provider because a key exists. Latency and privacy are worse than on-device, so it stays off by default. Design: documents/plans/2026-09-19-voice-p7-free-voice-path.md §3 design B.
