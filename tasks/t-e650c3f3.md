## Description

From documents/hermes-v0.21.1-whole-surface-audit.md (class 2). Brief: documents/hermes-v0.21.1-parity-agent-brief.md. A PyYAML parse failure makes Hermes discard the ENTIRE config.yaml layer (gateway/config.py:786-791 at v2026.9.7), so every writer must emit YAML PyYAML accepts. Verify each fix by round-tripping the emitted text through `python3 -c 'import yaml,sys; print(yaml.safe_load(sys.stdin))'` in a test.
1. GatewayConfigWriter.swift:78-79,313,414-431 hardcodes keyIndent 2 / itemIndent 4; derive from the located section's first body line; match keys at the section's own indent (a 4-space section currently gets an indent-2 key spliced → parse error, and an existing 4-space key is duplicated).
2. GatewayConfigWriter.swift:278-293,512,433: non-empty inline flow mapping (`slack: {reply_to_mode: first}`) falls to `.platformMissing` → duplicate top-level key clobbers the original. Expand the flow pairs into block rows, or refuse the write and return false.
3. GatewayConfigWriter.swift:538-556 `yamlQuoteIfNeeded`: add flow indicators `[ ] { } , ! % ` ?` and reject/quote embedded `\n`/`\r`; GatewayBehaviorViewModel.swift:150-152 trims only .whitespaces.
4. HermesFileService.swift:605-615 (client_cert), 627-632 (client_key), 645-650 (ssl_verify), 735-740 (cwd): route through `Self.yamlScalar` like setMCPServerCommand (:764).
5. HermesFileService.swift:556-563 addMCPServerSSE: propagate the transport-stamp Bool; on false return nonzero with a clear message.
6. HermesYAML.swift:81,84,243-255: CRLF input drops every section header; strip `\r` per line.
7. HermesYAML.swift:173-183: treat any `afterColon` starting with `|` or `>` (after comment strip) as a block header (`|-`, `|+`, `>-`, `|2`).
8. PlatformsViewModel.swift:106: recognise `slack: {}` and `slack:  # comment` as present sections (split at first `:`).
9. GatewayConfigWriter.swift:217-221: fix the `saveList` doc (must run off the main actor; caller detaches for a reason).

## Shipped

Commit `bf1645b1` on `fix/whole-surface-audit` ("fix(config): stop the config.yaml writers from emitting YAML PyYAML rejects"). All nine findings fixed; none disputed.

Premise re-verified at the tag: `git -C ~/.hermes/hermes-agent show v2026.9.7:gateway/config.py` lines 776-791 — bare `except Exception` around `config_loader.load_yaml_layer`, logs "Failed to process config.yaml — falling back to .env / gateway.json values." and continues. A PyYAML error costs the whole layer.

1. **Indents derived, not assumed** — `GatewayConfigWriter.locateBlock` now returns a `BlockIndents` taken from the section's own first body line (key indent) and the block's own first bullet (item indent); step = body indent, so 2-space files stay byte-identical (`  key:` / `    - item`) and 4-space files get 4/8. Key matching moved from `indent == 2` to `indent == bodyIndent`; block-membership from `indent == 4 || indent == 2` to `indent >= keyIndent`.
2. **Non-empty inline flow mapping** — new `expandTopLevelFlowMapping` rewrites `slack: {a: b, c: d}` into a block mapping (quote-aware comma split, trailing comment preserved) before locating. Nested / unparseable content is REFUSED, not guessed.
3. **`yamlQuoteIfNeeded`** — added `[ ] { } ,` (anywhere) and `! % \` ? =` (leading) plus a tab check; CR/LF-bearing items are refused up front. `GatewayBehaviorViewModel` trims `.whitespacesAndNewlines`.
   New `GatewayConfigWriter.WriteOutcome { updated / unchanged / refused }` with `setListChecked` / `setMapChecked`; `saveList` returns false on refusal (throws an internal `WriteRefusal` through `GuardedTextFile.mutate`), `PowerSettingsWriter` maps refusal → nil via `appliedText(orUnchanged:)` so its existing "return the input when unchanged" contract is preserved.
4. **`client_cert` / `client_key` / `cwd`** route through `Self.yamlScalar`. **`ssl_verify` deliberately does NOT for its bool form** — `yamlScalar` quotes `true`/`false` on purpose, and a quoted `"true"` is a CA-bundle *path* named `true` to Hermes (silent cert-verification downgrade). Bool → bare, path → `yamlScalar`. This was caught by the new test, not by the finding text.
5. **`addMCPServerSSE`** consumes the transport-stamp Bool; on false returns exit 1 with a message naming the entry and saying it is on disk as plain HTTP.
6. **`HermesYAML`** strips a trailing `\r` per line.
7. **Block-scalar headers** — new `isBlockScalarHeader` accepts `|`/`>` with chomping and/or explicit-indent indicators in either order plus a trailing comment (`|-`, `|+`, `>-`, `>+`, `|2`, `|2-`, `|  # note`).
8. **`PlatformsViewModel.computeConfiguredPlatforms`** splits at the first `:` (skips comments, `- ` rows, empty names) so `slack: {}`, `slack:  # note`, `slack: {a: b}` and CRLF all count as configured.
9. **`saveList` doc corrected** — states it must be called off the main actor (synchronous SCP round-trip + write-lock wait on `.ssh`), citing charter C10 and the caller's `Task.detached`.

## Fresh-eyes audit findings (found and fixed before commit)

- `containsLineBreak` used `String.contains("\n")`; `"\r\n"` is a single Swift grapheme cluster, so a CRLF paste sailed through. Rewrote over `unicodeScalars`. (Caught by the test, not by reading.)
- First cut used `keyIndent + 2` for item indent, producing a mixed 4/6 shape in a 4-space file. Changed to `step * 2` / `keyIndent + step`.
- Routing `ssl_verify` through `yamlScalar` wholesale turned `true` into the string `"true"` — a security-relevant behaviour change. Bool form now stays bare, pinned by `sslVerifyBooleansStayBooleans`.
- First cut asserted every hostile path must be quoted; plain scalars may legally contain spaces and (in block context) brackets/braces, so that assertion was wrong, not the code. Narrowed to the values a bare emission genuinely breaks.
- `PowerSettingsWriter` briefly returned nil for `.unchanged`, breaking two existing idempotence tests that assert the function returns the input. Added `WriteOutcome.appliedText(orUnchanged:)` so only refusal maps to nil.

## Deliberate no-ops / scope notes

- `setList` / `setMap` keep their String signatures and return the input unchanged on refusal; only `saveList` and `PowerSettingsWriter` (the write paths) surface it. Refusal reason strings are internal — `saveList` still reports the same `false` the UI already handles; no new user-facing string was added.
- A top-level section whose body is a bare sequence (`toolsets:\n- a`) still can't be spliced into; identical to the previous behaviour (`indent < 2` break), not a regression, and no gateway/platform section has that shape.
- Nothing capability-gated: every change is a correctness fix to Scarf's own emission/parsing, with no Hermes-version-dependent surface (charter C1 unaffected — the 2-space canonical shape is pinned byte-for-byte by `twoSpaceSectionIsUnchangedFromThePreviousRelease` and `ordinaryPathsAreStillEmittedBare`).
