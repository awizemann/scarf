## Description

From documents/hermes-v0.21.1-whole-surface-audit.md (class 2). Brief: documents/hermes-v0.21.1-parity-agent-brief.md. A PyYAML parse failure makes Hermes discard the ENTIRE config.yaml layer (gateway/config.py:786-791 at v2026.9.7), so every writer must emit YAML PyYAML accepts. Verify each fix by round-tripping the emitted text through `python3 -c 'import yaml,sys; print(yaml.safe_load(sys.stdin))'` in a test.
1. GatewayConfigWriter.swift:78-79,313,414-431 hardcodes keyIndent 2 / itemIndent 4; derive from the located section's first body line; match keys at the section's own indent (a 4-space section currently gets an indent-2 key spliced → parse error, and an existing 4-space key is duplicated).
2. GatewayConfigWriter.swift:278-293,512,433: non-empty inline flow mapping (`slack: {reply_to_mode: first}`) falls to `.platformMissing` → duplicate top-level key clobbers the original. Expand the flow pairs into block rows, or refuse the write and return false.
3. GatewayConfigWriter.swift:538-556 `yamlQuoteIfNeeded`: add flow indicators `[ ] { } , ! % ` ?` and reject/quote embedded `\n`/`\r`; GatewayBehaviorViewModel.swift:150-152 trims only .whitespaces.
4. HermesFileService.swift:605-615 (client_cert), 627-632 (client_key), 645-650 (ssl_verify), 735-740 (cwd): route through `Self.yamlScalar` like setMCPServerCommand (:764).
5. HermesFileService.swift:556-563 addMCPServerSSE: propagate the transport-stamp Bool; on false return nonzero with a clear message.
6. HermesYAML.swift:81,84,243-255: CRLF input drops every section header; strip `\r` per line.
7. HermesYAML.swift:173-183: treat any `afterColon` starting with `|` or `>` (after comment strip) as a block header (`|-`, `|+`, `>-`, `|2`).
8. PlatformsViewModel.swift:106: recognise `slack: {}` and `slack:  # comment` as present sections (split at first `:`).
9. GatewayConfigWriter.swift:217-221: fix the `saveList` doc (must run off the main actor; caller detaches for a reason).
