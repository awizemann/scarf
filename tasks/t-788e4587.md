## Description

Found while fixing t-30667749. Several scarfTests reach the REAL login-keychain item `com.scarf.miniapp-grants` / `hmac-key-v1` through MiniAppGrantSigner.signingKey() (e.g. ProjectTemplateUninstaller → ProjectLifecycleService.cleanUpAfterRemoval → MiniAppGrantStore.revokeAll). Every fresh unsigned test build triggers a keychain access prompt, which stalls the whole run (a 25-minute "hang"). Inject a test signing-key store so tests never touch the user's keychain. Memory: operations/mac-scarftests-run-green-only-serially-and-an-unsigned-test.
