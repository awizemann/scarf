## Description

From the 2026-09-19 review. Dictation (OnDeviceDictation, .playAndRecord/.measurement) and Live Voice (VoiceLiveAVAudioSession, .playAndRecord/.voiceChat/.defaultToSpeaker) each configure and deactivate AVAudioSession independently. F6-app adds a generation guard and category restore; the durable fix is a single owner/token type in ScarfIOS that both acquire, so a deferred deactivate can never fire under the other holder and the category is restored exactly once. Needs a real-device check (AirPods, speaker AEC, phone-call interruption).
