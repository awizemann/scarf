## Description

W1 (t-e2cd2861) fixed the DI-C2 class in ProjectContextBlock/ProjectAgentContextService, but the same `String(data:encoding:.utf8) ?? ""` block-splice shape survives at KeychainEnvMirror.swift:259 (env block rewrite) and ProjectTemplateInstaller.swift:131 (MEMORY.md appendix) — a non-UTF-8 byte collapses the existing file to empty before the splice. Apply the same refusal-on-undecodable + .bak treatment.

## Plan

Closed as part of G2 (t-58bc7efe). Both holes got the W1 `ProjectContextBlock.writeBlock` treatment — inspect through `GuardedJSONStore` (stat-confirmed proof + retried read), refuse undecodable UTF-8, keep a one-deep `.bak`, and treat zero bytes as `.absent` rather than damage (prose files, unlike JSON sidecars, are legitimately empty).

- `KeychainEnvMirror` (was line 259): `readExisting`/`writeIfChanged` replaced by `inspectEnv` + `text(of:at:)` + a guarded write. This one had BOTH halves of the DI-C2 bug — `fileExists`-as-proof AND the `?? ""` collapse — so a dropped SSH round-trip or one stray byte published a Scarf-block-only `~/.hermes/.env`, deleting Hermes's own ANTHROPIC_API_KEY along with everything else outside our markers. New `KeychainEnvMirror.EnvMirrorError` (refusedUnreadable / refusedUndecodableText / encodingFailed).
- `ProjectTemplateInstaller` (was line 131): the preflight collision check AND the real hole beside it at `appendMemoryIfNeeded` (line 212, `(try? readFile).flatMap { String(data:encoding:.utf8) } ?? ""` then `existing + appendix`) both go through new internal `inspectMemory` / `memoryText` helpers. New `ProjectTemplateError.memoryFileUnreadable` / `.memoryFileNotText`.

`GuardedJSONStore.Inspection.init` was made public so out-of-module prose writers can do the zero-bytes reclassification.

The `.env.bak` this now creates is covered by the same batch's SEC-L2 fix: `TransportPrivateMode` derives the mode from the ORIGINAL basename, so `.env.bak` is 0600 rather than world-readable.

Verified: ScarfCore 2134 tests, scarf scheme 712 tests, iOS build — all green.
