## Description

From F2a (t-dd450d3a). On the Mac, a spoken request cancels only turns the voice started itself; while a typed turn runs, the voice says Hermes is busy and a hint explains why. ScarfGo still cancels ANY running turn, typed or voice, so a spoken request silently kills a typed task. Bring ScarfGo's ChatController+VoiceTurnHost to the same rule and tests. Also use per-turn tokens so a late completion only clears its own turn (the Mac fix in 2fe27ad9).
