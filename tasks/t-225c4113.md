## Description

Add a ScarfCore helper (e.g. `EnvironmentHintComposer`): local compose(existingEnv:, configHint:, scarfHint:) -> String; remote shell fragment that expands the remote's own `$HERMES_ENVIRONMENT_HINT` after the login profile is sourced, falls back to the config hint, then appends Scarf's hint; shell-quoted via HermesProfileScope helpers.
