## Description

Found 2026-10-31 sampling Scarf Dev during a test run: the main thread sat near 0% idle, with most samples in RichChatMessageList.swift's ForEach reading @AppStorage (isHiddenByDensity via listToolCardStyle) and CFPrefs re-parsing the settings file. On Alan's Mac that file is 4.6 MB with 8641 keys: about 5340 scarf.hermesVersionLine.local|<temp or container path> (HermesVersionCache.swift:276) and about 3200 NSWindow Frame keys. Fix: read the density styles once before the ForEach; give the test host its own defaults domain or suite so tests don't write to the real one; stop caching version lines for throwaway homes; offer a one-time cleanup of the stale keys. Inferred, not proven: the test run's writes invalidate the app's settings cache, since the stall began within a minute of the suite starting.
