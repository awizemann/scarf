## Artifacts

Landed (branch main, uncommitted — the user commits).

**New**
- `scarf/Packages/ScarfCore/Sources/ScarfCore/Services/GuardedJSONStore.swift` — the read-then-write discipline as ONE type: stat+retry absent-vs-unreadable probe, zero-bytes-is-damage, quarantine (dedup by size+bytes, filename-safe UTC stamp), one-deep `.bak`, atomic publish, `GuardedStoreError.refusedUnreadableOverwrite`.

**Changed**
- `MiniAppGrantStore` — `load()`/`persist()` replaced by a single-inspection `mutate {}`; refuses over an unreadable/zero-byte file, quarantines undecodable bytes then rebuilds, keeps `.bak`.
- `SessionAttributionService` — same shape; `attribute`/`forget` go through `mutate {}`; prunes on every persist.
- `SessionProjectMap` — additive optional `touched` (sessionID → ISO-8601) + `prune(limit:)` at `maxMappings = 2000`; unstamped entries prune first, ties break on session id.
- `ProjectDashboard.swift` — `ProjectEntry.extra` and `ProjectRegistry.extra` (`[String: JSONValue]` via `AnyCodingKey`) preserve unknown keys across decode/encode; excluded from `==`/`hash`.
- `ProjectDashboardService` — `quarantineRegistry`/`quarantineStamp` delegate to `GuardedJSONStore`.
- `ModelPresetService` — `shared(for:)` per-`ServerContext` instance (NSLock table); all 6 call sites switched. `ModelPresetStoreReader.probe()` distinguishes `.presets/.absent/.unreadable`; `presetIDs()` logs instead of swallowing.
- `IOSCronViewModel` — keeps a byte `baseline` from `load()`; refuses a stale-clobber, refuses over an unreadable file, keeps `jobs.json.bak`, publishes through `GuardedJSONStore`.
- iOS `ProjectsListView` — `loadRegistryDetailed()`, damage banner row, and "Projects couldn't be read" instead of "No projects yet" on a damaged empty read. iOS `ProjectPickerSheet` — same detailed load; blocking loss fills the existing error slot.
