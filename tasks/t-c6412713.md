## Description

Package.resolved is gitignored (.gitignore:30) and SwiftTerm is required as upToNextMajor from 1.0.0 (scarf/scarf.xcodeproj/project.pbxproj ~1151). A fresh clone or worktree resolves the newest SwiftTerm 1.x, which fails at EmbeddedSetupTerminal.swift:194 (getTerminal missing). The maintainer's checkout pins 1.13.0 locally, so releases are fine, but contributors building from source break. Decide: commit Package.resolved, or tighten the requirement (exact / upToNextMinor 1.13.0), or adapt the code to the newer SwiftTerm API. Also consider -onlyUsePackageVersionsFromResolvedFile in ui-gate.sh / release.sh archive.
