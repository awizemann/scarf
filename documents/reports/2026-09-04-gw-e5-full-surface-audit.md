## Verdict

The arc's core discipline holds under attack: healthy-path byte parity at every converted writer, .bak-skipped-on-quarantine enforced centrally, one-inspection-carried-to-write everywhere, the proof-token editor pattern sound, no C10 regressions, no C3/C9 violations, atomic-write parity intact through the rename, and the highest-value attack (symlink-planting .env.bak for key exfiltration) empirically verified closed. What the audits found splits into: (a) READ-side inference the write-side arc didn't cover — the same absent-vs-unreadable disease one hop upstream of the new guards; (b) refusals landing in channels users can't perceive (green-checkmark-for-failure, no VO announcements); (c) the refusal doctrine inverted once into an attacker tool (uninstall aborts before Keychain cleanup).

## Security (1 HIGH, 3 MEDIUM, 4 LOW)

- **H F1** ProjectTemplateUninstaller.swift:419 — stripMemoryBlock's new memoryFileUnreadable throw aborts uninstall BEFORE step 4a Keychain deletion; chmod 000 MEMORY.md = attacker-controlled persistence of template secrets. Fix: catch → warning → continue to cleanup (ProjectLifecycleService.swift:96-106 is the in-repo template). Zero-length and non-UTF-8 paths do NOT abort — only unreadable.
- **M F2** LocalTransport.swift:113-120 publishes then chmods (try?-swallowed): fresh .env.bak lands 0644 in a window (0755 via pre-planted symlink); SSH/Citadel both fixed this the other way with doc comments saying why. Fix: temp + fchmod before rename.
- **M F3** GuardedJSONStore.inspect reads the whole file before testing maxBytes (doc claims otherwise); quarantine doubles residency; ProjectTemplateUninstaller.swift:914 passes Int.max on an agent-writable file; IOSMemoryViewModel pulls a multi-GB MEMORY.md whole on iOS → jetsam. Fix: stat-first refusal past cap; kill the Int.max.
- **M F4** Scanner evasions: wrapper laundering (one annotation, N callers); Foundation Data.write invisible (12 sites, mostly benign exports — docstring overclaims); consecutive-line annotation inheritance (previous-line rule accepts an inline-annotated line as the "annotation line" for the next call — tighten to isComment(previous)). #if branches are NOT an evasion (textual scan sees more than the compiler).
- LOWs: SkillsScanner filters .bak not .corrupt- (picker shows/edits quarantine copies); servers.json artifacts (host/user inventory) at 0644, not in TransportPrivateMode; guard artifacts accumulate inside the WebView-served mini-app root; oversized .env quarantine doubles secret footprint + freezes writes (availability-only, document as accepted).
- Held: symlink-planting at .bak/.corrupt- cannot redirect bytes on any transport (empirically verified — but incidentally, via Foundation atomic-write semantics, NO regression test pins it); existing-file permissions survive rewrites; TransportPrivateMode covers .env artifacts recursively; refuseForever applied centrally to both damage branches; uninspected publish refused; SkillsViewModel unsavable-by-construction; quarantine never eats the .bak; SHA-256 quarantine dedup; path containment on the skill editor; C3; C9.
