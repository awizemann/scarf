# Scarf v3.3.0 release prep — 2026-09-22

## Scope (v3.2.0 → main, 131 commits ahead of origin)

Minor bump: the release carries genuine new user-facing features (voice).

- **Voice conversation** (Mac + ScarfGo): chained mode (free, on-device STT, Hermes v0.20.1+) and GPT-Live mode (OpenAI real-time, Hermes v0.21.3+, consent + cost display). Capability flags: `hasHermesSpeechSynthesis` (v0.20.1), `hasGPTLiveVoice` (v0.21.3).
- **Hermes Voice playback** (Mac, Settings → Voice → Playback Engine).
- **ScarfGo dictation** (on-device only). Builds on @danmarauda's PR #143 (still open upstream — consider closing with a thank-you pointing at the release).
- Chained echo/barge-in fix (0abea0a3), P7 Mac/iOS audit fixes.
- Costs: unknown cost renders as a dash (b0f9ddc5, 3a1d9873, 30a323f0); Dashboard "By model · all time" (e8bc1008).
- Chat: window close stops ACP, config reads off main, composer a11y/IME/image cap (63e9c466); Kanban badge lifecycle (d58e74c3).
- ScarfGo: UTF-8 across SSH packets (a353c378); scripts on stdin, local too (834467ab); new wiki page Troubleshooting-ScarfGo-SSH-Stdin-Timeout.
- Under the hood: tests off the real Keychain, UI gate RUNNER-FAILED verdict, i18n for voice strings, privacy policy voice section.

No `gh#` issues fixed in this range (gh#124 was already closed; #143 is the contributor PR).
