# Scarf v3.7.0 release prep (2026-10-26)

Minor release: Hermes v0.22.5 support (v0.21.6–v0.22.5). Follows `scarf-release-prep`. Source material: `documents/plans/2026-10-24-hermes-v0-22-5-audit-and-plan.md`, memory notes `decisions/hermes-v0-22-compatibility-decisions` and `architecture/hermes-v0-22-wire-verification`.

## Scope

`git log --oneline v3.6.0..main` at prep time: 29 commits (57a14bae … 9c68e072), local main 29 ahead of origin before the prep commit.

- **Headlines:** gateway-backed chat (resume of CLI/TUI/Desktop chats, `/queue`, clarify cards with Skip = decline, model-switch confirmation, closing Scarf doesn't stop a turn); gateway live-session guard (confirm before `--yes`, never kill after a refusal; `restart --detach` for hand-run gateways; incompatible-owner status); strict YAML loader (duplicate keys flagged and refused on save; bare y/n quoted); plugins that left core (memory providers, Home Assistant, Spotify, Singularity) with Install/Enable; sessions show `created_source`.
- **Every host:** prompt usage replaced not summed; `status --all` only where `hasStatusSummaryDefault` (old hosts printed API keys); vLLM/llama.cpp/local → custom alias.
- **Smaller:** plugin enable/disable output, dependency consent via `plugins enable`, partial import, cron interpreter, Solstice/krea-3/rentahuman, Tirith hidden ≥0.21.6, ACP-missing hint, kanban diag kinds, skills restore, Health newer-than-stable, epoch-bounded recency.
- **Under the hood:** capability flags, table checker inline registrations, UI gate in a Tart VM.
- **Late addition (separate agent, landing before the cut):** reopening a CLI/TUI chat on 0.22.3+ uses that chat's own working folder; a missing folder falls back to a new chat. Already described in the notes (chat headline) and Home.md.
